**Proyecto: Campus Hub – Portal Universitario**

**Repositorio de GitHub:**
https://github.com/Rodrigolega/Web_Page_Campus

**Aplicación desplegada en Render:**
https://web-page-campus.onrender.com/

Campus Hub es una propuesta de portal universitario que busca reunir información académica, deportiva y actividades de interés para los estudiantes.

Actualmente cuenta con una vista previa funcional y responsiva, navegación entre secciones y contenido de demostración. El proyecto continuará desarrollándose para incorporar funcionalidades adicionales.
